# 翻译助手

一个轻量的 Windows 桌面翻译工具，基于 Electron + React + TypeScript 构建，调用 OpenAI 兼容的大语言模型 API，支持中、英、日三语互译。

> 输入即翻译，选中即翻译，常驻系统托盘，不打扰你的工作流。

---

## ✨ 核心功能

### 1. 主窗口翻译
- 左侧输入原文，右侧实时显示译文。
- 支持 **中 / 英 / 日** 三语互译，源语言可选"自动检测"。
- 输入后自动触发翻译（600ms 防抖），无需手动点击。
- **自动切换目标语言**：源语言为"自动"时，输入中文自动切英文目标，输入英文自动切中文目标，避免"中译中"的尴尬。
- 一键交换源语言与目标语言。
- 翻译结果支持 **TTS 朗读**（根据目标语言自动选择语音）。

### 2. 划词翻译（Cross Selection）
- 在任意软件中选中文字，按下 `Ctrl + Shift + C`。
- 程序自动模拟复制操作，并在鼠标附近弹出迷你翻译窗口。
- 弹窗同样支持**自动切换目标语言**。
- 弹窗支持切换目标语言，一键复制译文。
- 划词翻译的默认目标语言可在设置中配置并持久化。

### 3. 剪贴板监听（复制即翻译）
- 开启后，复制任意文本自动弹出迷你翻译窗口。
- 主窗口聚焦时不弹窗，避免打扰正在输入的用户。
- 设置中可随时开关，实时生效。

### 4. 截图 OCR 翻译
- 使用 Windows 截图工具（`Win + Shift + S`）截图后，在输入框中 `Ctrl + V` 粘贴。
- 自动 OCR 识别图片中的文字并翻译。
- 支持中文、英文、日文识别。

### 5. 翻译结果增强
- **译文**：基于大语言模型的自然翻译。
- **读音**：日文结果提供罗马音，英文结果视情况提供音标。
- **备选译法**：最多提供 3 种不同译法，方便选择。
- **语言检测**：源语言设为"自动"时，显示检测到的语言。

### 6. 翻译历史
- 自动保存最近 20 条翻译记录。
- 在左侧「翻译历史」面板中点击任意记录即可回填到主窗口。
- 支持单条删除与一键清空（带确认弹窗）。

### 7. 收藏夹
- 翻译结果旁 ⭐ 收藏按钮，已收藏高亮显示，避免重复收藏。
- 左侧「收藏夹」面板支持搜索、添加备注、删除、导出为 `.txt` 文件。
- 独立持久化，不受历史 20 条上限限制。

### 8. 术语库
- 左侧「术语库」面板可添加专业术语和指定译法。
- 翻译时通过 Prompt 注入术语表，让模型优先遵循你的术语定义。
- 支持增删改查和搜索，独立持久化。

### 9. 文档翻译
- 支持拖拽 `.txt`、`.md` 文件到主窗口输入区。
- 自动读取文件内容并填入输入框，触发翻译。
- 支持将翻译结果导出为 `.txt` 文件。

### 10. 快捷键自定义
- 设置中可自定义全局快捷键。
- 支持显示/隐藏主窗口、划词翻译两个快捷键的自定义。
- 保存后自动重新注册，即时生效。

### 11. 多模型对比翻译
- 当配置了 ≥2 个模型的 API Key 时，可在设置中开启"对比翻译模式"。
- 同时调用多个模型，结果区以卡片形式并排展示各模型译文。
- 单个模型失败不影响其他模型，失败卡片会显示错误信息。
- 开启时提示会消耗更多 Token。

### 12. 划词翻译弹窗固定
- 划词翻译弹窗右上角可点击固定（Pin）。
- 固定后弹窗不会因失去焦点而自动关闭，方便对照查看。

### 13. 翻译结果自动复制
- 设置中可开启"翻译结果自动复制"。
- 翻译完成后自动将译文复制到剪贴板。
- 多模型对比模式下复制默认模型或第一个成功模型的译文。

### 14. 语音输入
- 在翻译输入框点击 🎤 麦克风按钮，或按全局快捷键 `Ctrl + Alt + V` 即可录音。
- 应用内录音时，窗口底部居中弹出浮动录音面板：左 X 取消、中声音波动动画、右 ✓ 完成。
- 应用外（如浏览器、编辑器）按 `Ctrl + Alt + V` 会弹出基于划词翻译弹窗风格的迷你录音浮层，同样支持取消 / 完成。
- **取消**会立即停止录音并丢弃音频，不会识别、不会优化、不会粘贴；**完成**会停止录音并继续识别 → 优化 → 填入输入框（应用内）/ 粘贴到外部窗口（应用外）。
- 支持智谱 AI ASR 或本地 whisper.cpp 两种识别服务。
- 可选开启「口语内容优化」，使用 DeepSeek 将啰嗦、重复的口语提炼为简洁精准的书面语后再翻译。
- 左侧「语音优化记录」面板可查看原始识别文本与优化后文本的对比，最多保存 20 条，点击可回填到翻译输入框。
- 可在设置中开关语音输入、切换识别服务、开关口语优化、配置默认识别语言、自定义语音输入快捷键。

### 15. 外观与交互
- 支持 **浅色 / 深色 / 跟随系统** 三种主题。
- 无边框窗口 + 自定义标题栏，支持窗口置顶。
- **左侧侧边导航栏**：翻译、术语库、收藏夹、翻译历史、语音优化记录、设置六入口，点击切换右侧面板。
- **侧边栏可折叠**：展开显示图标+文字，收起仅显示图标，切换按钮位于侧边栏顶部。
- 全局快捷键 `Ctrl + Shift + T` 快速显示/隐藏主窗口（可自定义）。
- 最小化到系统托盘，托盘图标支持显示/隐藏与退出。

### 16. 多模型支持
- 内置 **DeepSeek、OpenAI、Gemini、智谱 AI** 四个提供商。
- 设置面板选择默认模型，只展示选中模型的配置。
- 所有提供商均通过 OpenAI 兼容的 `/chat/completions` 接口调用。
- 配置多个 API Key 后，可开启"对比翻译模式"同时调用多个模型对比结果。

## 🚀 快速开始

### 环境要求

- Windows 10 / 11
- Node.js 20+
- 任意一个 OpenAI 兼容的 API Key

### 安装依赖

```bash
npm install
```

### 开发运行

```bash
npm run dev
```

### 配置 API Key

首次运行时打开应用：

1. 点击左侧「设置」菜单。
2. 在"默认翻译模型"中选择你想使用的提供商（DeepSeek / OpenAI / Gemini / 智谱 AI）。
3. 在下方配置卡片中填写：
   - **API Key**：你的 API Key
   - **Base URL**：API 地址（已预填默认值，一般无需修改）
   - **模型**：模型名称（已预填默认值）
4. 离开设置页时自动保存，即可开始翻译。

### 语音识别准备（可选）

语音输入支持两种识别服务，可在设置中切换：

**方式一：智谱 AI ASR（推荐）**
- 使用智谱 AI 的 `glm-asr-2512` 模型
- 需要在设置中配置智谱 AI 的 API Key
- 无需本地二进制文件和模型

如开启「口语内容优化」，还需要配置 DeepSeek API Key，用于将口语化识别结果提炼为简洁书面语。

**方式二：本地 whisper.cpp**
- 完全离线，无需联网
- 需要准备 whisper.cpp 的 Windows 可执行文件：
  1. 自行编译 [whisper.cpp](https://github.com/ggml-org/whisper.cpp) 得到 `whisper-cli.exe`，或从可信来源获取 Windows 预编译版本。
  2. 将 `whisper-cli.exe` 放到项目 `resources/whisper/whisper-cli.exe`。
  3. 首次使用语音输入时，应用会自动下载 `ggml-base-q8_0.gguf` 模型（约 75MB）到用户数据目录。

打包时 `resources/whisper/` 会通过 `extraResources` 包含在安装目录中。

## 🏗️ 技术栈

- **Electron** — 跨平台桌面应用框架
- **Vite** + **electron-vite** — 快速构建与热更新
- **React 19** + **TypeScript** — 渲染层 UI
- **Tailwind CSS** — 原子化样式
- **Zustand** — 轻量状态管理
- **electron-store** — 本地设置与历史持久化
- **koffi** — Windows 原生 API 调用，实现划词复制
- **tesseract.js** — 离线 OCR 文字识别
- **whisper.cpp** — 离线语音识别（语音输入转文字）
- **DeepSeek** — 口语内容优化、翻译

## 📁 项目结构

```
translation-assistant/
├── src/
│   ├── main/           # Electron 主进程：窗口、托盘、LLM 请求、OCR
│   ├── preload/        # Preload 脚本（CJS），暴露安全 IPC 桥接
│   ├── renderer/       # React 渲染层
│   │   ├── components/ # UI 组件
│   │   ├── hooks/      # 共享 Hooks（如 useTheme）
│   │   └── stores/     # Zustand 状态管理
│   └── shared/         # 主/渲染共享类型
├── electron.vite.config.ts
├── package.json
└── README.md
```
