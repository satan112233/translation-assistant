# 翻译助手

一个轻量的 Windows 桌面翻译工具，基于 Electron + React + TypeScript 构建，调用 OpenAI 兼容的大语言模型 API，支持中、英、日三语互译。

> 输入即翻译，选中即翻译，常驻系统托盘，不打扰你的工作流。

---

## ✨ 核心功能

### 1. 主窗口翻译
- 左侧输入原文，右侧实时显示译文。
- 支持 **中 / 英 / 日** 三语互译，源语言可选"自动检测"。
- 输入后自动触发翻译（600ms 防抖），无需手动点击。
- **自动切换目标语言**：源语言为"自动"时，输入中文自动切英文目标，输入英文自动切中文目标，避免"中译中"的尴尬。
- 一键交换源语言与目标语言。
- 翻译结果支持 **TTS 朗读**（根据目标语言自动选择语音）。

### 2. 划词翻译（Cross Selection）
- 在任意软件中选中文字，按下 `Ctrl + Alt + X`。
- 程序自动模拟复制操作，并在鼠标附近弹出迷你翻译窗口。
- 弹窗同样支持**自动切换目标语言**。
- 弹窗支持切换目标语言，一键复制译文。
- 划词翻译的默认目标语言可在设置中配置并持久化。

### 3. 剪贴板监听（复制即翻译）
- 开启后，复制任意文本自动弹出迷你翻译窗口。
- 主窗口聚焦时不弹窗，避免打扰正在输入的用户。
- 设置中可随时开关，实时生效。

### 4. 截图 OCR 翻译
- 使用 Windows 截图工具（`Win + Shift + S`）截图后，在输入框中 `Ctrl + V` 粘贴。
- 自动 OCR 识别图片中的文字并翻译。
- 支持中文、英文、日文识别。

### 5. 翻译结果增强
- **译文**：基于大语言模型的自然翻译。
- **读音**：日文结果提供罗马音，英文结果视情况提供音标。
- **备选译法**：最多提供 3 种不同译法，方便选择。
- **语言检测**：源语言设为"自动"时，显示检测到的语言。

### 6. 翻译历史
- 自动保存最近 20 条翻译记录。
- 在历史面板中点击任意记录即可回填到主窗口。
- 支持单条删除与一键清空（带确认弹窗）。
- 历史面板打开时，聚焦输入框会自动关闭面板。

### 7. 收藏夹 / 生词本
- 翻译结果旁 ⭐ 收藏按钮，已收藏高亮显示，避免重复收藏。
- 收藏夹面板支持搜索、添加备注、删除、导出为 `.txt` 文件。
- 独立持久化，不受历史 20 条上限限制。

### 8. 外观与交互
- 支持 **浅色 / 深色 / 跟随系统** 三种主题。
- 无边框窗口 + 自定义标题栏，支持窗口置顶。
- 全局快捷键 `Ctrl + Shift + T` 快速显示/隐藏主窗口。
- 最小化到系统托盘，托盘图标支持显示/隐藏与退出。

### 9. 多模型支持
- 内置 **DeepSeek、OpenAI、Gemini、智谱 AI** 四个提供商。
- 设置面板以单选按钮选择默认模型，只展示选中模型的配置。
- 所有提供商均通过 OpenAI 兼容的 `/chat/completions` 接口调用。

## 🚀 快速开始

### 环境要求

- Windows 10 / 11
- Node.js 20+
- 任意一个 OpenAI 兼容的 API Key

### 安装依赖

```bash
npm install
```

### 开发运行

```bash
npm run dev
```

### 配置 API Key

首次运行时打开应用：

1. 点击右上角 **设置** 按钮。
2. 在"默认翻译模型"中选择你想使用的提供商（DeepSeek / OpenAI / Gemini / 智谱 AI）。
3. 在下方配置卡片中填写：
   - **API Key**：你的 API Key
   - **Base URL**：API 地址（已预填默认值，一般无需修改）
   - **模型**：模型名称（已预填默认值）
4. 点击保存即可开始翻译。

## 🏗️ 技术栈

- **Electron** — 跨平台桌面应用框架
- **Vite** + **electron-vite** — 快速构建与热更新
- **React 19** + **TypeScript** — 渲染层 UI
- **Tailwind CSS** — 原子化样式
- **Zustand** — 轻量状态管理
- **electron-store** — 本地设置与历史持久化
- **koffi** — Windows 原生 API 调用，实现划词复制
- **tesseract.js** — 离线 OCR 文字识别

## 📁 项目结构

```
translation-assistant/
├── src/
│   ├── main/           # Electron 主进程：窗口、托盘、LLM 请求、OCR
│   ├── preload/        # Preload 脚本（CJS），暴露安全 IPC 桥接
│   ├── renderer/       # React 渲染层
│   │   ├── components/ # UI 组件
│   │   ├── hooks/      # 共享 Hooks（如 useTheme）
│   │   └── stores/     # Zustand 状态管理
│   └── shared/         # 主/渲染共享类型
├── electron.vite.config.ts
├── package.json
└── README.md
```
